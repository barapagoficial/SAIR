# SAIR

**SAIR** es una aplicación web de roleplay con personajes de IA. Crea tus propios personajes, chatea con ellos y vive historias que recuerdan lo que pasó.

**👉 https://barapagoficial.github.io/SAIR/**

## Qué puedes hacer

- ✨ **Crear personajes** con su personalidad, escenario, saludo y aura, o generarlos con IA a partir de una idea.
- 💬 **Chatear y rolear**, con varias versiones de cada respuesta, edición de mensajes y lectura en voz alta.
- 🧠 **Memoria del chat**: los chats largos se resumen solos para que el personaje no olvide la historia.
- 📖 **Historiador, Recapitulación y Diario de Personajes** para revivir y repasar tus historias.
- 🌍 **Comunidad**: descubre y comparte personajes, dales «me gusta» y guárdalos en favoritos.
- ⚡ **Créditos de Rol**: rolea sin configurar nada, o usa gratis tu propia API Key de Gemini.
- 📲 **Instálala** en tu móvil o PC como una app.
